# Signal & Co. — Practice SEO Website

A 7-page static site (Home, About, SEO Services, Social Media Marketing, Google Ads, Blog, Contact) for practicing on-page and technical SEO.

## Host it free on GitHub Pages

1. Go to https://github.com and create a free account (if you don't have one).
2. Click the **+** icon (top right) → **New repository**.
   - Name it: `signal-co-website` (or anything you like)
   - Set it to **Public**
   - Click **Create repository**
3. On the new repo page, click **uploading an existing file**.
4. Drag in all the files from this folder (`index.html`, `about.html`, `seo-services.html`, `social-media-marketing.html`, `google-ads.html`, `blog.html`, `contact.html`, `style.css`).
5. Click **Commit changes**.
6. Go to **Settings** (top of the repo) → **Pages** (left sidebar).
7. Under **Build and deployment** → **Source**, choose **Deploy from a branch**.
8. Under **Branch**, choose `main` and folder `/ (root)` → click **Save**.
9. Wait 1–2 minutes, then refresh the Pages settings tab — you'll see your live URL:
   `https://yourusername.github.io/signal-co-website/`

That's it — the site is free, live, and has a real indexable URL you can use to practice submitting to Google Search Console.
